# مجلد أغانى وزفات المناسبات (Music & Audio Tracks)

مجلد الأصول الصوتية والموسيقى المتاحة في المنصة.

## 🎵 إضافة ملفات الموسيقى المباشرة

1. **عند وضع ملف صوتي جديد** (`.mp3`, `.wav`, `.m4a`, `.ogg`) داخل هذا المجلد، يقوم الموقع بقراءته وإضافته إلى قائمة الصوتيات المتاحة بالمنصة.
2. **طريقة تسمية الملفات**: يمكنك تسمية ملف الصوت باستخدام الشرطة `-` لتحديد (قسم الأغنية - اسم الأغنية)، مثل: `زفات مصرية - طلة العروسة الملكية.mp3`.
