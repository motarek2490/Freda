# Romantic Canvas (لوحة الحب الحية)

Module ID: `romantic-canvas`
Layout Type: `arabic`
Version: `1.0.0`

## Structure

- `Template.tsx`: Main layout orchestrating all sections with scroll-reveal animations.
- `config.ts`: Template capabilities, supported features, default luxury palette.
- `styles.css`: Fully isolated style rules scoped under `.template-romantic-canvas`.
- `canvas/`: HTML Canvas engine for the living heart, particles, and petals.
- `components/`: Hero, Countdown, and ActionButton sub-components.

## Creative Concept

A cinematic living artwork — not a webpage. The invitation opens with a luminous
heart being drawn by light on a dark atmospheric canvas, followed by a gentle
zoom-out reveal of the couple's names. The entire experience feels like a
romantic painting brought to life.
